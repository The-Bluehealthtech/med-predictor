# PCMA — recherche CIM-11 OMS (30 septembre 2026)

## Changements
- Recherche ICD-11 MMS dans les antécédents cardiovasculaires, le contexte
  chirurgical et les allergies, sur les formulaires de création et de modification.
- Plusieurs codes possibles par catégorie ; suppression et rechargement des choix.
- Résolution serveur du code et du libellé OMS : les valeurs client ne sont pas
  utilisées comme référentiel. Stockage dans la base principale, result_json :
  medical_history.{cardiovascular,surgical,allergies}_icd11_codes.
- Notes cliniques libres préservées. Aucune conclusion ni signature automatique.
- Recherche protégée par connexion, rôle médical et limitation de fréquence.
- OAuth serveur uniquement ; aucun secret transmis au navigateur.
- URI des appels limitée à https://id.who.int ; identifiants d'entité numériques.
- Version, langue et provenance stockées. Configuration ICD11_RELEASE, défaut
  2026-01. ICD11_BASE_URL doit être https://id.who.int.
- Le code BA00 historique est conservé à la lecture et repris dans le formulaire.
  La sélection via le nouveau formulaire remplace ce champ historique.
- Les erreurs OMS/authentification/timeout affichent une indisponibilité explicite.
- Aucun nom de joueur ni dossier clinique transmis à l'OMS, seulement le terme
  saisi dans la recherche ou la référence de code sélectionnée.

## Limites
La sélection reste médicale et manuelle. La postcoordination et les règles de
codage complexes ne sont pas automatisées. La CIM-11 ne remplace pas la CCAM
pour les actes chirurgicaux. Les notes de codage retournées sont conservées.
Les identifiants OMS configurés par l'utilisateur en production n'ont pas pu être
vérifiés depuis une session médicale authentifiée : le navigateur cloud est
bloqué par 2Key. Les tests HTTP utilisent des réponses OMS simulées.

## Vérification
38 tests PCMA réussis, 317 assertions. Contrats OMS simulés : recherche, langue,
droits médicaux, choix des trois catégories, persistance/suppression, rejet des
URI arbitraires, libellés client ignorés, token renouvelé après 401, configuration
absente, timeout, réponse malformée et entité inconnue. Syntaxe PHP/JS et diff
vérifiés. Validation visuelle dans la session 2Key et appel OMS réel non effectués.
